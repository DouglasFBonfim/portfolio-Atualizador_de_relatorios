## 🇧🇷 Português

### DTC Atualizador — hub cliente/servidor

**Role / Papel / Rol:** Hub de sincronização e integração (modo servidor/cliente)  
**Stack:** `Delphi, PostgreSQL, HTTP/REST, integrações externas`

#### Problem / Problema
Vários bancos e sistemas externos precisavam de um hub Windows capaz de sincronizar dados e configurações em arquitetura distribuída.

#### Solution / Solução / Solución
Sistema Delphi com modos servidor e cliente, API HTTP autenticada e conectores para integrações externas de operação.

#### Highlights
- Arquitetura servidor/cliente
- API REST com autenticação
- Múltiplas integrações

## 🇬🇧 English

### DTC Updater — client/server hub

**Role / Papel / Rol:** Sync and integration hub (server/client modes)
